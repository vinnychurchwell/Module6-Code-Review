# Module 6: Individual Code Review and Documentation Project

This project demonstrates refactoring a Python script to improve naming, documentation, and readability while producing the assignment's required output.

## Files
- `undocumented_script.py`: Refactored program.
- `CODE_REVIEW.md`: Initial observations and final review.
- `DECISIONS.md`: Explanation of design decisions.
- `SCREENCAST_TALKING_POINTS.md`: Suggested outline for the required screencast.

## Run the program
Use Python 3:

```bash
python undocumented_script.py
```

Expected output:

```text
Processed Numbers: [3, 4, 9, 8, 15, 12, 21]
Processed Strings: apple BANANA kiwi GRAPEFRUIT CHERRY
```
