# Screencast Talking Points (3–5 minutes)

1. **Introduction (20–30 seconds):** Introduce the Module 6 code review and documentation project. Explain that the goal is to make a Python script clearer and easier to maintain while meeting the required output.
2. **Initial review (40–50 seconds):** Show the starter script, if available. Explain that generic names, missing docstrings, and manual list construction made the code harder to understand.
3. **Code improvements (60–90 seconds):** Open `undocumented_script.py`. Point out the descriptive function and variable names, docstrings, list comprehensions, and targeted comment. Explain why each change helps.
4. **Run the program (30–45 seconds):** Run `python undocumented_script.py`. Show the expected output:
   - `Processed Numbers: [3, 4, 9, 8, 15, 12, 21]`
   - `Processed Strings: apple BANANA kiwi GRAPEFRUIT CHERRY`
5. **Documentation (30–45 seconds):** Open `CODE_REVIEW.md`, `DECISIONS.md`, and `README.md`. Summarize what each file documents.
6. **GitHub (30–45 seconds):** Show your actual GitHub repository, required files, and commit history. Do not claim that you pushed or committed anything until you have completed those steps.

Speak in your own words and keep the terminal and code visible while recording.
